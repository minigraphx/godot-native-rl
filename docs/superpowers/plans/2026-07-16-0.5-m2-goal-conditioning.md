# 0.5 M2 — Goal Conditioning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add goal-conditioned observations (Unity goal-signal parity) — a `GoalSensor` obs channel + a "GoToGoal" multi-goal trained example where one policy reaches whichever target is signaled, proven load-bearing by a goal-blind ablation.

**Architecture:** A dimension-agnostic `GoalSensor` (extends `Node`, like `RunningNormSensor`) emits a `num_goals`-wide one-hot of the current goal, pulled from the game via a duck-typed `get_current_goal()`. It's auto-discovered by `collect_sensors()` and concatenated after the perception sensor. Training is **stock PPO** (the goal is just obs — no new trainer). A `goal_blind` export on the sensor zeroes the channel for the control regression.

**Tech Stack:** GDScript (Godot 4.5+), Python 3.13 (`.venv-train`), stock SB3 PPO `MultiInputPolicy` over `StableBaselinesGodotEnv` (the gridworld trainer template).

## Global Constraints

- GDScript **TAB** indentation; **path-based** `extends "res://addons/godot_native_rl/sensors/i_sensor_2d.gd"` etc., never bare `class_name`. (repo convention)
- Sensor width is **config-fixed** — `obs_size()` returns `num_goals` and never varies with the current goal (the RelativePositionSensor stability rule).
- `object_paths`/typed-Node-**array** exports do not resolve at runtime instantiation in hand-authored `.tscn` — use `Array[NodePath]`; a **single** `NodePath` export (`goal_source_path`) is fine.
- Deploy scenes need a `Sync` node even for pure inference (the sorter gotcha); the trained-checker must `seed_rng()` then re-roll the first layout (#298/#300).
- Reward accumulation happens **before** relocating a target (seek baseline-rebase gotcha).
- Python: 4-space indent; heavy imports lazy in `main()`. Every change ships tests; `./test/run_tests.sh` + CI on Godot 4.5/4.6 green before merge.

```gdscript
# Pure goal-signal encoding (#386). one_hot(goal_id, num_goals) -> num_goals floats, 1.0 at goal_id.
# `blind` or an out-of-range goal_id -> all zeros (the goal-blind ablation + the invalid fallback).
static func one_hot(goal_id: int, num_goals: int, blind: bool = false) -> Array:
	var out: Array = []
	out.resize(num_goals)
	out.fill(0.0)
	if not blind and goal_id >= 0 and goal_id < num_goals:
		out[goal_id] = 1.0
	return out
```

```gdscript
extends Node
# Goal-signal obs channel (#386): a num_goals-wide one-hot of the current goal, auto-discovered by
# collect_sensors() (has both get_observation() + obs_size()). Dimension-agnostic (a goal id has no
# 2D/3D split). The goal is pulled from `goal_source_path` (duck-typed get_current_goal()) when set,
# else from the pushed `current_goal`. `goal_blind` zeroes the channel — regression-only, NEVER set
# in a shipped scene (the goal-blind control that proves the signal is load-bearing).

const GoalMath = preload("res://addons/godot_native_rl/sensors/goal_math.gd")

@export var num_goals: int = 2
@export var goal_source_path: NodePath = ^""
@export var goal_blind: bool = false

var current_goal: int = -1
var _source: Node = null
var _warned := false

func set_goal(id: int) -> void:
	current_goal = id

func obs_size() -> int:
	return num_goals

func _resolve_goal() -> int:
	if goal_source_path != ^"":
		if _source == null:
			_source = get_node_or_null(goal_source_path)
		if _source != null and _source.has_method("get_current_goal"):
			return int(_source.get_current_goal())
		if not _warned:
			push_error("GoalSensor: goal_source_path %s has no get_current_goal(); emitting zeros." % str(goal_source_path))
			_warned = true
		return -1
	return current_goal

func get_observation() -> Array:
	return GoalMath.one_hot(_resolve_goal(), num_goals, goal_blind)
```
