# 0.5 M1 — Discrete Action Masking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add per-decision discrete action masking (Unity `WriteDiscreteActionMask` parity) full-stack — an additive `action_mask` wire field, MaskablePPO training, and native masked ncnn inference at deploy — demonstrated on GridWorld.

**Architecture:** Masking is applied in two independent places that share one agent method `get_action_mask() -> Dictionary` (keyed like the action space, `{"move":[1,1,0,1,1]}`, 0=invalid): (1) **deploy** — `ActionDecode.decode_actions` sets masked logits to a fp16-safe `-6e4` sentinel before argmax/sample; (2) **training** — a new additive `action_mask` step/reset wire field is surfaced to sb3-contrib MaskablePPO via a `MaskableStableBaselinesGodotEnv`. Deploy masking works on the already-shipped GridWorld net (decode-side, no retrain); training masking is the parity deliverable.

**Tech Stack:** GDScript (Godot 4.5+), Python 3.13 (`.venv-train`), sb3-contrib 2.8.0 MaskablePPO (already an opt-in dep from #378 via `requirements-recurrent.txt`), godot_rl `StableBaselinesGodotEnv`.

## Global Constraints

- GDScript uses **TAB** indentation. Prefer path-based `extends "res://addons/..."`, not bare `class_name`. (repo convention)
- Python: 4-space indent; stdlib `unittest` under `test/python/`; keep heavy imports (torch/SB3/sb3-contrib) lazy inside `main()` / guarded so pure helpers stay import-free. (repo convention)
- The wire change is **additive and backward-compatible**: the `action_mask` key is emitted only when ≥1 training agent implements `get_action_mask()`; stock godot_rl 0.8.2 ignores unknown keys (same invariant proven by `truncated` #12). Pre-mask scenes and the Python side default to all-ones.
- Masking is **discrete/multi-discrete only**; continuous action keys are never masked.
- The masked mask sentinel is **`-6e4`** (fp16-safe; matches the attention-encoder convention). Never emit an all-zero mask row (GridWorld action 0 = "stay" is always valid, guaranteeing ≥1 valid action).
- Every change ships with tests; `./test/run_tests.sh` + CI on Godot 4.5 and 4.6 must be green before merge.

```gdscript
const MASKED_LOGIT := -6.0e4  # fp16-safe (min fp16 ~= -6.55e4); matches the attention-encoder mask sentinel

# #385: return a copy of `logits` with masked (mask[i]==0) slots set to MASKED_LOGIT, so argmax
# can never select them and softmax gives them sampling probability exactly 0 (exp underflows).
# Fails loud but never bricks inference: a size mismatch or an all-masked row returns the logits
# UNMASKED (the caller degrades to ordinary argmax) — Unity contractually requires >=1 valid action.
static func apply_action_mask(logits: PackedFloat32Array, mask: Array) -> PackedFloat32Array:
	if mask.size() != logits.size():
		push_error("apply_action_mask: mask size %d != logits size %d; ignoring mask." % [mask.size(), logits.size()])
		return logits
	var any_valid := false
	for v in mask:
		if int(v) != 0:
			any_valid = true
			break
	if not any_valid:
		push_error("apply_action_mask: all actions masked; ignoring mask (falling back to unmasked argmax).")
		return logits
	var out := logits.duplicate()
	for i in range(out.size()):
		if int(mask[i]) == 0:
			out[i] = MASKED_LOGIT
	return out
```

```python
def flatten_mask_dict(mask_dict, action_keys, key_sizes):
    """Concatenate per-key 0/1 masks in `action_keys` order (the env_info action-space order the
    MultiDiscrete nvec was built from). A missing/None key defaults to all-ones (#385)."""
    out = []
    md = mask_dict or {}
    for key in action_keys:
        m = md.get(key)
        if m is None:
            out.extend([1] * key_sizes[key])
        else:
            out.extend(int(v) for v in m)
    return out
```
